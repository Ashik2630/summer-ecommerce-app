# 🛒 Summer Card E-commerce Store

## 📌 Project Overview
This project is a simple and responsive e-commerce web application built for showcasing and purchasing summer-related products. Users can explore different items, view details, and experience a smooth shopping interface.

The main goal of this project is to practice building a modern full-stack web app with authentication, protected routes, and a clean UI.

---

## 🚀 Live URL
👉 https://summer-ecommerce-app.vercel.app

---

## 🎯 Purpose
- To build a functional e-commerce platform
- To understand authentication and protected routes
- To practice working with modern tools like Next.js and MongoDB
- To improve UI/UX design using Tailwind CSS and component libraries

---

## ✨ Key Features

- 🔐 **Authentication System**
  - Login & Register functionality
  - Secure user authentication using BetterAuth

- 🔒 **Protected Routes**
  - Product details page is protected
  - Profile page is protected
  - Users are redirected to login if not authenticated

- 🛍️ **Product Management**
  - Product listing page
  - Category-based filtering
  - Individual product details page

- 👤 **User Profile**
  - View user profile
  - Update profile information

- 🎨 **UI & Design**
  - Fully responsive design (mobile, tablet, desktop)
  - Smooth animations using Framer Motion
  - Clean and modern interface

- 📢 **Extra Sections**
  - Summer cards section
  - Tips section
  - Top brands in footer
